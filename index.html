How this works

The test downloads and uploads data to the nearest Cloudflare edge server for a few seconds each and measures how many megabits per second got through. Latency is the median of twenty small round trips with the server's own processing time removed; probes that never return count as packet loss. While the link is saturated the test keeps pinging, and the rise in latency is your bufferbloat. The readiness grades turn all of that into what matters: will the film buffer, will the game lag, will the call freeze. Wi‑Fi, time of day and other devices all move the numbers, so run it two or three times for a fair picture.
